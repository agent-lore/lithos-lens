{#- The knowledge graph's shared macros: imported by the page and by its panel partial, which `/knowledge/graph/panel` renders alone (K2 D10), so a node and a panel link read the same in both. -#} {#- A node as the text names it: a ghost by its short id, never a link; any other node by its label (its title, or its full id when unread), linked to its note, marked when its facts are pending a re-read. -#} {% macro node_ref(node) -%} {%- if node.is_ghost -%} {{ node.label }} note not found {%- else -%} {{ node.label }} {%- if node.facts_state == "pending" %} facts pending{% endif %} {%- endif -%} {%- endmacro %} {#- The attributes of a link that opens a panel (`edge=` or `selected=`): a plain href to the page with that one selection — the no-JS baseline — and, with htmx, the panel fragment for the same scope fetched into the page's panel host, the address bar following the href.
