What this identity is, and what it is not

Lens has no authentication or authorization. Anyone who can reach this port can perform these actions. It is built for a single operator on a trusted local network; do not expose it beyond one.

This identity is an attribution label: it names who a write is recorded as in Lithos, and it proves nothing about who sent the request. The same goes for the two request-level checks Lens does run — the Origin/Referer check on every write POST, and registering this id as a human before its first write. Both are hygiene, not security.

Writes are never attributed to Lens's own service agent ({{ config.lithos.agent_id }}), and an id that already belongs to an agent is refused rather than quietly re-typed as a human.
