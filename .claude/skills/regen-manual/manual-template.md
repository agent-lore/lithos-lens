# Lithos Lens User Manual

Lithos Lens is a web window onto **Lithos**: the tasks agents are working on, the dependency graph between them, the findings they post, and the knowledge notes and the typed edges between those notes. It updates live as Lithos emits events. Reading never changes anything; a small set of curated write actions is available once you choose an operator identity, and each shows its consequences before anything is written.
